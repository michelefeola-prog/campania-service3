ANTEPRIMA SUL COMPUTER
1. Estrai tutto lo ZIP in una cartella.
2. Apri index.html con Chrome, Edge o Firefox.
3. Visita le altre pagine dal menu.
Per i font Google e la mappa serve una connessione Internet.

PUBBLICAZIONE SU UN NUOVO REPOSITORY GITHUB
1. Crea un nuovo repository, per esempio campania-service-oro.
2. Scegli Public se utilizzi GitHub Pages con un account gratuito.
3. Seleziona Add file > Upload files.
4. Carica tutti i file estratti e la cartella images.
   index.html, style.css e script.js devono essere nella radice del repository.
   Non caricare soltanto lo ZIP e non inserire index.html in una sottocartella.
5. Conferma con Commit changes sul branch main.
6. Apri Settings > Pages.
7. In Build and deployment seleziona Deploy from a branch.
8. Seleziona main e / (root), poi Save.
9. Attendi che GitHub Pages mostri il link pubblicato.

Esempio di indirizzo, se scegli il nome campania-service-oro:
https://michelefeola-prog.github.io/campania-service-oro/
Questo indirizzo diventa attivo soltanto dopo la pubblicazione.

I repository delle altre versioni restano separati.
Puoi mostrare le tre versioni con tre link differenti.
Non servono installazioni, npm o compilazioni.
